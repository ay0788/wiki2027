# MyWiki 2027 - Plateforme Collaborative

![MyWiki 2027 Logo](https://github.com/ay0788/wiki2027/blob/main/logo.png)

## 📚 À propos

MyWiki 2027 est une plateforme collaborative conçue pour centraliser et faciliter l'accès aux ressources pédagogiques au sein de l'École des Sciences de l'Information (ESI). Ce projet vise à améliorer le partage de connaissances, la collaboration entre étudiants et enseignants, et à préserver le patrimoine intellectuel de l'établissement.

## 🎯 Objectifs

- Centraliser les ressources éducatives de l'ESI
- Faciliter la collaboration entre étudiants et enseignants
- Améliorer l'accessibilité des contenus pédagogiques
- Encourager le partage de connaissances entre différentes promotions
- Créer un espace dynamique évoluant avec les besoins des utilisateurs

## 🛠️ Technologies Utilisées

| Catégorie       | Technologies        | Justification                      |
|-----------------|---------------------|-----------------------------------|
| Frontend        | HTML5, CSS, JavaScript | Interface responsive et interactive |

| Base de données | MongoDB             | Stockage flexible des données      |

## 🔍 Principales Fonctionnalités

### 🏠 Page d'Accueil
- Bannière de bienvenue
- Visite guidée pour nouveaux utilisateurs
- Carrousel d'actualités et événements
- Accès rapides personnalisables

### 📖 Section Academic
- Bibliothèque numérique organisée par filière, niveau et discipline
- Filtres avancés de recherche
- Prévisualisation des documents
- Archives académiques et projets remarquables
- Annales d'examens

### 🤖 Bot des Lauréats
- Exploration des parcours professionnels des anciens diplômés
- Sélection par filière d'intérêt
- Profils détaillés des lauréats
- Connexion aux profils LinkedIn
- Facilitation de prise de contact

### 🎭 Section Activités
- Catalogue des activités académiques et extra-académiques
- Présentation des clubs et associations
- Ateliers thématiques et conférences
- Galerie multimédia des événements passés

### ❓ FAQ
- Base de connaissances structurée par thèmes
- Système de questions-réponses communautaire
- Évaluation des réponses par la communauté
- Indications sur l'officialité des informations

### 💬 Forum
- Espaces de discussion organisés par thématiques
- Forums généraux et spécifiques par filière
- Forums temporaires pour projets collaboratifs
- Espaces d'entraide et de résolution de problèmes

## 🚀 Installation et Démarrage

```bash
# Cloner le dépôt
git clone https://github.com/username/mywiki-2027.git

# Naviguer vers le répertoire du projet
cd mywiki-2027

# Installer les dépendances
npm install

# Démarrer l'application en mode développement
npm run dev

# Construire pour la production
npm run build
```

## 📊 Analyse SWOT

### Forces
- Interface intuitive
- Forte dimension collaborative
- Intégration du Bot IA
- Design responsive

### Faiblesses
- Courbe d'apprentissage pour certaines fonctionnalités avancées
- Dépendance à une connexion internet stable
- Ressources initiales limitées
- Optimisation nécessaire pour certains navigateurs

### Opportunités
- Extension à d'autres établissements
- Développement de modules complémentaires
- Partenariats avec des entreprises
- Communauté d'utilisateurs grandissante

### Menaces
- Concurrence d'autres plateformes éducatives
- Évolution rapide des technologies web
- Enjeux de protection des données
- Maintenance à long terme

## 🔮 Perspectives d'Évolution

- Développement d'une application mobile dédiée
- Intégration de fonctionnalités avancées d'intelligence artificielle
- Extension à d'autres établissements partenaires
- Création d'un écosystème d'extensions et de modules complémentaires
- Mise en place d'un système de certification pour les contributions majeures

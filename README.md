## MyWiki 2027

Le projet MyWiki 2027 a été développé avec plusieurs objectifs stratégiques:
Créer une plateforme centralisée pour les ressources éducatives de l'ESI
Faciliter la collaboration entre étudiants et enseignants
Améliorer l'accessibilité des contenus pédagogiques
Encourager le partage de connaissances entre les différentes promotions
Créer un espace dynamique qui évolue avec les besoins des utilisateurs
